vscode 多窗口进程，逻辑上有个同一个主进程，它在第一次启动 vscode 的时候被启动，后续窗口进程都由它派生，而且会继承它的环境变量。
这就导致一个问题，如果主进程是由终端通过 code 启动，终端的环境变量会被 vscode 主进程继承，进而被所有 vscode 窗口/子进程继承……造成环境变量泄露。

所以用终端 code 命令启动 vscode 务必小心，若主进程仍未启动，可以这样：



1. 不注入环境变量，执行 code --new-window
2. 等待主实例就绪
3. 注入环境变量，然后执行 code --reuse-window "项目目录" 

对于后续启动子进程/窗口，已验证，VS Code 会通过IPC还是什么机制，为子进程单独注入它启动时的环境变量。
