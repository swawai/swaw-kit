Core 只验证 Manifest 中的依赖身份与 Provider State 的静态 Ready，不读取或注入业务工具环境。
该 Consumer 通过 Dev Runtime 提供的薄消费库读取并复验 `environment.json`、
脚本、PATH 与可执行物，再把同一份 Export 导入当前进程；不会回退到系统 cl.exe。

这也演示了两条所有权边界：run.ps1 由当前 Runtime 固定的 Framework Pwsh 执行，
具体 MSVC/Windows SDK 由 `.dev/setup` 发布，并由实际 Consumer 在使用边界校验。
