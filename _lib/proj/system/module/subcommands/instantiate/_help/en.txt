Build a System or Module command declaring execution.native as an independent run.exe and publish a content-addressed Release. A logical port declaring execution.delegate automatically targets its explicit native owner in the same command space.

Usage: {{INVOCATION}} <native-command-or-logical-port-address>

Normal command execution never compiles source. This command consumes the product builder environment pinned by bootstrap.json and published by the physical `_bootstrap/setup.ps1`; it does not depend on `.dev/setup`. Run this command again after a source change; a failed build does not replace the current Release.
