深度检查 .dev/setup 发布的一个 Export。

用法：
  {{INVOCATION}} environment
  {{INVOCATION}} environment --json

environment 检查会验证当前 Provider State、environment.json schema 与发布身份、env.cmd 和 env.ps1 的生成字节、已声明的 PATH 目录，以及已声明的 Bun 或 PowerShell 可执行文件。它只读，不会运行 .dev/setup 或其它 Entry 命令。

退出码 0 表示 Export 已就绪。退出码 1 表示发布缺失、过期、无效或物理内容不完整。无效参数属于命令错误。JSON 输出使用 swawkit.proj.dev-setup-check/v2。
