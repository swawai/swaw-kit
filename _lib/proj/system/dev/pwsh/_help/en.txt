Run a script or command with the PowerShell 7 selected by Dev Settings and verified by .dev/setup.

Usage:
  {{INVOCATION}} -File <path.ps1> [arguments...]
  {{INVOCATION}} -Command <script...>

Managed mode uses .dev/setup PowerShell; system mode requires a probed PowerShell 7+; disabled mode rejects this command and all run.ps1 entries. The adapter does not fall back to Windows PowerShell 5.1, load user Profiles, or accept interactive input. Relative script paths resolve from the command working directory.
