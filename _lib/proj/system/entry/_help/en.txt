Inspect and maintain the current Entry project binding and development Profile.

Usage:
  {{INVOCATION}}
  {{INVOCATION}} --json

Project binding, interface language, and Git settings use typed commands below
{{ADDRESS}}. Development-tool settings live below the matching .dev tool node.
Entry instances must be created explicitly, and legacy DataRoots require an
explicit migration. Instance identity comes from data/proj.<entry>/entry.id,
not a Launcher FileId. Replacing the EXE at the same path neither reclaims nor
changes the Entry identity.
Only the swawkit manager may inspect instances with .entry/instances, create
one with .entry/instances/create, or explicitly migrate a same-name legacy
instance with .entry/instances/migrate. Cold migration of the manager itself
remains a bootstrap.ps1 -MigrateLegacyManagerDataRoot operation.

This Entry command remains available when the Profile is missing or invalid.
