Create a new Entry instance.

Usage: .entry/instances/create <entry-name> [--json]

Names are 1..48-byte lower-kebab ASCII, start with a lowercase letter, end with
a lowercase letter or digit, and contain no consecutive hyphens, for example
proj1 or proj-one. swawkit and Windows DOS device names are reserved. Only the
swawkit manager can run this command; it creates the root Launcher, isolated
DataRoot, and current Runtime copy.

Creation atomically commits the complete DataRoot before publishing the root
Launcher. launcher.json records the target name, Launcher length, and SHA-256.
Retrying an interrupted publication completes the Launcher from that receipt.
If the manager has selected a new Runtime while its Host still runs the old
Release, creation requires a Host restart instead of mixing generations.
The command never migrates a legacy DataRoot implicitly or creates a desktop
shortcut.
