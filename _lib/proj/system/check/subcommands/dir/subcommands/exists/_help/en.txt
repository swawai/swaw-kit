Check whether a physical resource in a Provider's public export subtree is an existing safe directory.

Usage:
  {{INVOCATION}} <provider>::export[/<path>]
  {{INVOCATION}} <provider>::export[/<path>] --json

The resource locator names one Provider command followed by a path in its public export subtree. This command only reads the Catalog and filesystem metadata. It never runs the Provider or changes the resource. It does not check Provider State, prove publication readiness, or replace Consumer validation.

Exit code 0 means the resource is an existing directory. Exit code 1 means it is missing, is not a directory, or crosses an unsafe filesystem entry. Invalid locators and invalid Provider declarations are command errors. JSON output uses swawkit.check.dir-exists/v1.
