只读检查指定命令的入口与输入依赖是否可以立即执行。

用法：
  {{COMMAND}} .check <command-address>
  {{COMMAND}} .check <command-address> --json

该命令只读取 Catalog、模块 swawkit.module.json、Provider State 与 Export 顶层目录，
不会运行目标命令，也不会安装、编译或修复任何内容。退出码 0 表示命令入口和
所有已声明输入依赖均 Ready；退出码 1 表示当前不能执行。

swawkit.module.json 使用 swawkit.command-module/v11，消费方通过 requires 声明
Provider 命令、具名 Export 与 contract。检查不评价目标自身的 provides；要确认某个
Provider 的产物能否消费，应检查实际 Consumer。Provider 若提供普通子命令
<provider>/check，结果会给出可显式运行的检查命令，但不会自动执行它。
--json 输出 swawkit.command-check/v2，适合 Agent、脚本和可视化消费。
