安装 Bun 并生成项目开发环境脚本。

用法:
  {{INVOCATION}}

当前 V0 只处理已经迁移完成的 Bun 模块。安装位置:
  SWAWKIT_PROJ_DATA_ROOT/dev_env/bun/installs/<version>

同时生成:
  SWAWKIT_PROJ_DATA_ROOT/dev_env/env.cmd
  SWAWKIT_PROJ_DATA_ROOT/dev_env/env.ps1

该命令不接受动态参数，也不修改用户或系统 PATH。

Bun 默认通过 GitHub Release API 解析指定版本并使用可用的 digest 校验。
可在 swawkit.cmd 中设置 SWAWKIT_PROJ_BUN_SHA256 进一步锁定安装包；
未设置时只给出黄色提示，不阻塞安装。
