进入当前项目的系统 Windows PowerShell 会话。

用法:
  {{INVOCATION}}

.ps 固定启动 Windows 自带的 Windows PowerShell 5.1，不通过 PATH
选择 pwsh.exe。未来的 .pwsh 将作为独立命令提供。

新会话以项目根目录为当前目录，并继承由 Proj Core 验证和激活的
SWAWKIT_PROJ_*、SWAWKIT_DEV_* 与开发工具 PATH。

会话 PATH 还会临时加入当前 Proj 内核的 _bin 目录；不会修改用户
或系统 PATH。输入 exit 返回原终端。

该命令不接受动态参数。
