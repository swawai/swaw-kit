# Git 身份包装器:
  {{COMMAND}}               用当前 Git 身份打开默认终端
  {{COMMAND}} .help zh      显示中文版帮助
  {{COMMAND}} .help en      Show English help, output
  {{COMMAND}} .info         显示当前配置，和已生效的 Git 身份信息


# 同步到当前仓库:
  {{COMMAND}} .sync              将当前身份持久写入当前仓库的 .git/config
  {{COMMAND}} .sync --dry-run    只显示将写入什么，不修改 .git/config
  {{COMMAND}} .sync --clear      清理上次 .sync 写入且未被改动的值。

# 编辑器和终端启动器:
  {{COMMAND}}               用当前 Git 身份打开配置的默认终端
  {{COMMAND}} .code .       用当前 Git 身份启动 VS Code 打开当前目录
  {{COMMAND}} .cursor .     用当前 Git 身份启动 Cursor
  {{COMMAND}} .cmd          用当前 Git 身份打开 cmd.exe
  {{COMMAND}} .ps           用当前 Git 身份打开 PowerShell 5  （系统自带的老版本）
  {{COMMAND}} .pwsh         用当前 Git 身份打开 PowerShell 7+ （需自行安装）

# 自定义命令参数都以点号开头，其他命令会在注入身份后直接透传给 git 例如:
  {{COMMAND}} status
  {{COMMAND}} commit -m "message"
  {{COMMAND}} push

# 新建身份：① 如 copy git1.cmd git2.cmd ② 修改 git2.cmd 中定义的身份信息 ③ git2 --help
